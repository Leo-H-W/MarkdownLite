# LightMDKit - 仓库概览

> 本文档是项目知识库的索引和导航，用于快速了解项目结构和查找详细文档。

## 基本信息

| 项目名称 | LightMDKit |
|---------|--------|
| 项目简介 | 免安装的本地 Markdown 工作台：以 GitHub 风格渲染与编辑本地 Markdown 文件，文件不上传，支持目录导航、在线编辑、拖放打开与 Mermaid 图表 |
| 主要语言 | JavaScript（Node.js + 浏览器原生 JS，无 TypeScript） |
| 核心框架 | Express 4.18（后端）、marked 12（Markdown 解析）、CodeMirror 5（编辑器）、Mermaid 11（图表）、github-markdown-css 5（排版） |
| 分析版本 | 工作区代码，其内容已全部提交在 `main` 上，最新提交 `bf3f988` |
| 生成时间 | 2026-09-11 |

> ⚠️ **关于分析版本与行号口径**：本文档与 `doc/kb` 下的其余文档，描述的都是 **2026-09-11 的工作区代码**，
> 其内容已提交在 `main` 上（最新 `bf3f988`，此前经过 `f71e683` 侧边栏功能 → `dc57969` 现代模式增强 →
> 之后若干表格与新建文件的修复）。
> **核对行号请直接读工作区文件**（如 `sed -n '<行号>p' public/app.js`）；`main` 上更早的提交
> （如 `3bbca34`）不含这些能力，行号对不上。

## 模块功能介绍

### 核心模块

| 模块名称 | 功能描述 | 目录路径 | 相关技术 |
|---------|---------|---------|---------|
| 后端服务 | HTTP 服务器（默认端口 **3456**），托管前端静态资源；提供文件夹选择、加载目录、读取文件、刷新文件 4 个 API；含端口占用检测、后台守护进程拉起、自动打开浏览器 | `LightMDKit/server.js` | Express 4.18, Node.js (`child_process`/`net`/`os`) |
| 前端界面 | 单页应用：工具栏、侧边栏导航、正文渲染区、编辑器；负责文件夹句柄管理、文件渲染、TOC 生成、编辑与自动保存、拖放打开、新建文件、传统/现代双模式 | `LightMDKit/public/app.js` | 原生 JS（IIFE，约 2150 行）、File System Access API、IndexedDB |
| 渲染管线 | **前后端共用**的 Markdown 渲染模块：缩进保留、表格多行单元格合并、`~` 删除线分词补丁；UMD 双端导出 | `LightMDKit/public/md-render.js` | UMD 包装、marked 12 自定义 tokenizer（200 行） |
| 页面与样式 | 页面骨架（工具栏 + 侧边栏 + 内容区 + 拖放遮罩）与全部样式，含现代模式（`.live-preview` 作用域）的即时渲染规则 | `public/index.html`、`public/style.css` | HTML5, CSS3, 三方库本地引入（`public/vendor/`，离线可用） |
| 打包脚本 | `pkg` 打包后改写 exe 的 PE 头 Subsystem 为 `WINDOWS_GUI`，消除双击时的命令行窗口 | `LightMDKit/scripts/set-windows-gui.js` | Node.js `fs`（直接操作 PE 二进制） |
| 启停脚本 | 一键启动（检查 Node 环境、缺依赖自动 `npm install`）与停止后台服务 | `LightMDKit/start.bat`、`start.sh`、`stop.bat`、`stop.sh` | Windows Batch / POSIX Shell |

### 公共模块

| 模块名称 | 功能描述 | 目录路径 |
|---------|---------|---------|
| 渲染管线 | 唯一被前后端同时消费的模块 —— `server.js` 通过 `require('./public/md-render.js')` 引用，浏览器通过 `<script src="md-render.js">` 引用。**修改 Markdown 语义时必须同时考虑两侧** | `LightMDKit/public/md-render.js` |
| 文件类型判定 | `isMarkdownName(name)` 判定 `.md` / `.markdown`，被目录扫描与拖放打开共用 | `LightMDKit/public/app.js:179` |
| UI 偏好持久化 | 界面模式、侧边栏视图等偏好统一以 `lightmdkit.` 前缀存入 `localStorage`，读写均 `try/catch` 降级 | `LightMDKit/public/app.js` |

## 主要能力一览

| 能力 | 说明 | 关键标识 |
|------|------|---------|
| 递归目录扫描 | 侧边栏文件浏览器递归进入子目录并按目录分组；有深度与数量上限，跳过无意义目录 | `SCAN_MAX_DEPTH`(=6)、`SCAN_MAX_FILES`(=3000)、`SCAN_SKIP_DIRS`（`node_modules`/`.git`/`dist` 等） |
| 文件标识为相对路径 | 文件记录为 `name` + `path`（相对目录根，`/` 分隔），解决不同子目录同名文件冲突 | `currentFiles[].path` |
| 路径归一化匹配 | 文档内链接的 `./sub/a.md`、`sub/a.md`、`sub\a.md` 统一口径后匹配同一记录 | `normalizePathForMatch()` |
| 侧边栏视图切换 | 文件列表 ↔ 当前文档目录（TOC）一键切换，选择记忆在 localStorage | `lightmdkit.sidebarView`、`SIDEBAR_VIEW_KEY` |
| 文件列表实时过滤 | 按文件名 / 相对路径过滤，当前文件高亮 | `fileFilter`、`fileListEl` |
| 新建文件 | 工具栏「新文件」按钮（在「新tab页」之前）：弹窗输入文件名，在当前文件夹创建；含 6 类校验与写入异常提示 | `btn-new-file`、`createNewFile()`、`validateNewFileName()` |
| 刷新 | 重新扫描目录刷新文件列表 + 重读当前文档；没有打开文件时也会刷新列表 | `refreshCurrentFile()` |
| 现代模式（Typora 式） | 单栏常驻编辑：标题 / 加粗 / 斜体 / 行内代码 / 引用 / 列表圆点 / 任务框 / 代码围栏 / 表格 均即时渲染；回车列表续行 | `.live-preview`、`applySurface()` |
| 表格伪渲染 | 编辑器里把表格画成带框线的表格（CM5 不认表格，靠自研扫块 + `markText` + 按列宽注入样式表）；光标落在表头行时展开分隔行便于核对 | `refreshTableMarks()`、`#cm-table-style`、`updateSepReveal()` |
| 表格单元格按键 | Tab 新增一行、Enter 跳到下一行同一格、Ctrl+Enter 单元格内插入 `<br>` 换行 | `tableTabKey`、`tableEnterKey`、`tableCtrlEnterKey` |
