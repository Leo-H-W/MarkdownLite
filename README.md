# MarkdownLite

免安装的本地 Markdown 工作台，以 GitHub 风格渲染与编辑 Markdown 文件。无需上传文件，直接通过浏览器读取本地文件夹，支持目录导航、在线编辑、双编辑模式与 Mermaid 图表。

## 功能特性

- **GitHub 风格渲染** — 基于 `github-markdown-css` 与 `marked`，还原 GitHub 上的排版效果
- **本地文件夹加载** — 通过浏览器原生 [File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_Access_API)（`showDirectoryPicker`）直接读取本地目录，文件不上传；顶栏左侧的 **📁 加载文件夹...** 按钮负责选择目录，加载后可点同一个按钮更换目录
- **侧边栏文件浏览器** — 列出当前目录下所有可打开的文件，**递归进入子目录**并按目录分组展示，支持按文件名 / 路径实时过滤，当前文件高亮，点击即在该页打开（因此不再需要顶部的文件下拉框）
- **侧边栏视图切换** — 文件列表与当前文档目录（TOC）一键切换，选择记忆在浏览器本地
- **侧边栏目录（TOC）** — 自动提取标题生成目录，随滚动高亮当前章节，支持折叠与拖拽调整宽度
- **现代模式（Typora 式即时渲染，默认）** — 单栏常驻编辑，没有「编辑 / 浏览」按钮。标题、粗体、斜体、行内代码、引用、列表圆点、任务框、代码围栏与**表格**都按成品样式呈现，光标所在行还原成源码便于修改。**新用户/清过站点数据时默认就是它**；偏好记在浏览器本地，刷新后保持
- **传统模式** — 编辑与浏览分离：点 **编辑** 进入 CodeMirror 编辑器，点 **浏览** 保存并返回预览。**不是默认模式**，需要在顶栏的模式开关里主动切过来
- **自动保存（可开关，默认关闭）** — 顶栏的 **自动保存(5s)** 开关用于开启。开启后**停止编辑 5 秒**才写回磁盘（连续输入期间不写、内容没变不写）；关闭时一个字节都不写（点「浏览」或切模式时的显式保存不受影响）。偏好记在浏览器本地
- **新建文件** — 工具栏 **新文件** 按钮可在当前已加载的文件夹里创建 Markdown 文件，带文件名校验（非法字符、Windows 保留名、重名等）与写入异常提示
- **表格编辑** — 现代模式下表格可直接编辑：`Tab` 在格子间右移一格（在本行最后一格按，则在本行之后插入一行）、`Enter` 跳到下一行同一格、`Ctrl+Enter` 在单元格内插入换行（单元格随之变成多行，同行其它格子的高度一起撑开、位置不动）、光标（或鼠标）落到某个数据行时，该行最后一格右侧会出现「…」，点开是**行菜单**，可以删除这一行（分隔行不给这个入口 —— 删了表格就不再是表格）；落到**表头行**时，整张表的右边界外会出现「…」，点开是**表格菜单**，可以**删除整张表**（表头行 + 分隔行 + 全部数据行一并删掉，表格前后的空行不动；整表删除是一次原子编辑，`Ctrl+Z` 一步就能恢复）、`Backspace` / `Delete` 删的是整个 `<br>` 而不是一个一个字符，而且**只管当前单元格的内容**：顶到格子边界、行首 / 行尾都停住，不会吃掉 `|`、不会删隔壁格子的内容，也不会吞换行把两行并起来（只有确实渲染成表格的行才这么管，选中 `|` 或换行再删仍可手动删结构）
- **编辑 ↔ 浏览位置同步** — 切换模式时自动定位到当前标题对应的源码位置
- **Mermaid 图表** — 支持渲染 ` ```mermaid ` 代码块（传统模式）
- **文档内链接跳转** — 拦截相对路径的 Markdown 链接在同目录内打开，并提供「返回」历史栈
- **手动刷新** — 重新扫描文件夹并重读当前文档，感知新增 / 删除的文件
- **拖放打开** — 把 `.md` 文件或文件夹拖入页面，在新标签页中打开；文件位于当前已加载目录时，新标签页会自动定位到该目录

## 技术栈

| 组件 | 说明 |
| --- | --- |
| [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/) | 静态服务与后台守护进程 |
| [marked](https://marked.js.org/) | Markdown 解析 |
| [github-markdown-css](https://github.com/sindresorhus/github-markdown-css) | GitHub 排版样式 |
| [CodeMirror 5](https://codemirror.net/5/) | Markdown 编辑器 |
| [Mermaid](https://mermaid.js.org/) | 图表渲染 |

## 快速开始

```bash
# 安装依赖
npm install

# 启动服务（默认端口 3456）
npm start
```

启动后访问 <http://localhost:3456>。

`npm start` 会以守护进程方式在后台运行服务。再次启动时若检测到端口已被占用，会打印提示并直接打开浏览器访问地址（不会弹交互式菜单）。

## 使用说明

1. 使用 **Chrome / Edge** 浏览器打开 <http://localhost:3456>（文件夹选择依赖 File System Access API）
2. 点击顶栏左侧的 **📁 加载文件夹...** 按钮，选择包含 Markdown 文件的目录
3. 在左侧 **文件列表** 中点击文件即可打开；导航栏里的 **文件列表 / 目录** 用于切换面板，加载过目录后加载按钮变为 **更换文件夹...**
4. 在 **文件列表** 中可用过滤框按文件名或路径快速定位，子目录中的文件按目录分组显示
5. 点击 **编辑** 进入编辑模式，修改后点击 **浏览** 保存并返回预览；编辑状态下若已开启「自动保存」，停止输入 5 秒会写回一次（默认关闭）
6. 顶栏右侧的 **模式开关** 控制界面模式，**默认是现代模式**（滑块靠右、蓝色、标签「现代模式」）：单栏常驻编辑，没有「编辑 / 浏览」按钮，点进去直接打字即可。点一下切到 **传统模式**（滑块靠左、灰色、标签「传统模式」），变成编辑 / 浏览分离。**滑块位置和标签写的都是「当前」模式**，不用猜；选择记在浏览器本地，刷新后保持。两种模式的外观互不影响
7. 在**现代模式**下编辑表格：光标停在表头行时表右侧会出现 **⋯**，点开是表格菜单（**删除表格**）；光标停在数据行时该行右侧会出现 **⋯**，点开是行菜单（**删除本行**）
8. 点击 **新文件** 在当前文件夹新建 Markdown 文件（需先加载文件夹），创建后会自动打开
9. 点击 **刷新** 重新扫描当前文件夹（含子目录）并重读当前文档
10. 也可以直接把 Markdown 文件（或文件夹）从资源管理器拖入页面，会在新标签页中打开

### 现代模式的已知限制

现代模式是「带成品样式的源码视图」，以下内容**仍以源码形式显示**，不会渲染成最终形态：

- 图片与 Mermaid 图表（切回传统模式后正常渲染）
- 单元格内的鼠标拖拽选字会被点击落点修正逻辑拦截，可改用键盘选区

## 服务端 API

> 前端默认使用浏览器 File System Access API 读取文件，以下接口由服务端提供，可作为替代或扩展使用。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/select-folder` | 打开系统文件夹选择对话框（仅 Windows） |
| `POST` | `/api/load` | 扫描并加载目录中的 Markdown 文件 |
| `GET` | `/api/file` | 读取指定文件并渲染为 HTML |
| `POST` | `/api/refresh` | 刷新指定文件的渲染结果 |

## 项目结构

```
MarkdownLite/
├── server.js          # Express 静态服务 + 守护进程 + REST API
├── package.json
├── public/
│   ├── index.html     # 页面结构
│   ├── app.js         # 前端交互逻辑（含现代模式的即时渲染）
│   ├── md-render.js   # Markdown 渲染预处理（前后端共用，UMD）
│   └── style.css      # 自定义样式（含 .live-preview 现代模式规则）
├── checklist.md       # 验收清单：现代模式表格 / 自动保存（逐条记录期望效果）
├── scripts/
│   ├── set-windows-gui.js     # 打包后改写 exe 的 PE 子系统为 GUI
│   ├── checklist-check.mjs    # 按 checklist.md 校验表格各项（需本机有 playwright）
│   ├── autosave-check.mjs     # 校验自动保存开关与时机（同上）
│   ├── table-menu-check.mjs   # 校验表头「…」→ 删除表格，及表格块边界判定（同上）
│   ├── edit-modern-check.mjs    # 校验「文件列表点文件 → 点正文即可编辑」主链路，及默认现代模式 / 传统浏览态两个契约（同上）
│   ├── repro-table-modern.mjs   # 复现脚本：传统 / 现代两种模式下表格渲染对比（传统正常、现代曾显示不对）
│   └── repro-switch-folder.mjs  # 复现脚本：现代模式下更换文件夹后仍可编辑（6 个场景）
├── start.bat / stop.bat     # Windows 启动 / 停止脚本
├── start.sh  / stop.sh      # Linux / macOS 启动 / 停止脚本
├── doc/               # 知识库文档
├── openspec/          # OpenSpec 规范
├── agent-rules/       # Agent 规则提示词
└── test-*.md          # 示例 Markdown 文件
```
